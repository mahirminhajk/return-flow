# RETURN FLOW API

## Install
i use pnpm as package manager. you can use npm or yarn as well.
install pnpm globally
```bash
$ npm i -g pnpm
```
install dependencies
```bash
$ pnpm i
```

## Commands

### Run
```bash
$ pnpm run dev
```

### Build
```bash
$ pnpm run build
```

### Test
```bash
$ pnpm run test
```

### Test with watch mode
```bash
$ pnpm run test:watch
```
